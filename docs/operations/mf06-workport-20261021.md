# Concrete MF06 assessment WorkPort

Status: private composition implemented and checked on an owned PostgreSQL test
schema. Not registered as a NestJS/runtime worker; no website rollout or complete
MF06/identity/model acceptance.

## Implemented behavior

- Prepare claim/context, captured-authority archive and optional Face work outside
  the final database transaction. Caller JSON and crop bytes are privately copied;
  metadata is frozen and crops exceeding the existing2MiB policy are refused.
- Opaque WeakMap handles bind the original six claim fields and original context.
  Forged/copied handles and rotated leases cannot append assessments.
- The writable SERIALIZABLE finalizer acquires the ordered20-table SHARE fence
  before its first SELECT. It then locks/rechecks the original request/raw event,
  payload binding, archive, Camera/Region/version/status and original raw time.
- Qualified policy NONE records ALLOWED/POLICY_NONE; PROHIBITED_FOR_ALL records
  DENIED/POLICY_PROHIBITED. Neither invokes Face or establishes Worker identity.
- AUTHORIZATION_REQUIRED rechecks correlated candidate/profile metadata but records
  UNAVAILABLE/IDENTITY_UNAVAILABLE without trusted identity attestation. A correlated
  candidate is not a verified Worker or an access grant.
- Append/replay uses the same EntityManager and requestId as stable commandId.
  Existing Store lease/head/deadline guards and immutable history remain in force.
- Genuine40001/40P01 errors retain bounded transaction retries. Lock/statement/
  prerequisite availability errors55P03/57014/55000 request a new lease/preparation
  at the shared worker transaction boundary, including errors after the fence.
- A dependency ABORTED result cannot mint/append a result. Actual outer cancellation
  preserves cancellation semantics; without outer cancellation it requests a fresh
  bounded resolver attempt rather than inventing a user cancellation or recording
  a permanent unavailable assessment.

The WorkPort intentionally keeps fence/revalidation/append ordering together;
private preparation copying is separate. It is above the300-line target but below
the500-line review threshold. No formatting compression or safety checks removed.
